# ragas
RAGAS (Retrieval Augmented Generation Assessment)

> https://rifaterdemsahin.github.io/ragas/

RAGAS ("RAG assessment") is an open-source evaluation framework built specifically for retrieval-augmented generation pipelines. Its core idea is that you don't need a large hand-labeled test set to know whether a RAG system is any good — instead, RAGAS uses an LLM as an automated judge, scoring each answer along several dimensions using only the question, the retrieved context, and the generated answer (plus, optionally, a ground-truth answer for a couple of metrics).
